Quiz de revisão

Dificuldade: Revisão geral
Pré-requisito: todo o curso

Vinte perguntas cobrindo do básico ao avançado. Clique em uma alternativa para ver o feedback na hora.

1. Qual a diferença fundamental entre sobrecarga (overload) e sobrescrita (override)?

Sobrecarga é resolvida em compilação (mesma classe), sobrescrita em execução (herança).
São sinônimos, apenas nomes diferentes para o mesmo conceito.
Sobrecarga só existe em interfaces; sobrescrita só em classes abstratas.

2. Ao atribuir um objeto a outra variável (b = a), o que é copiado?

Uma cópia completa e independente do objeto no heap.
Apenas a referência (endereço) — ambas apontam para o mesmo objeto.
Só os atributos marcados como public.

3. Se você sobrescreve equals(), o que é obrigatório fazer junto?

Nada além disso — equals() funciona sozinho.
Sobrescrever hashCode() de forma coerente.
Tornar a classe final.

4. Atributos (campos) de instância têm ligação dinâmica (polimorfismo)?

Sim, exatamente como métodos sobrescritos.
Não — atributos usam o tipo da variável, resolvido em compilação.
Só se forem declarados protected.

5. Qual a diferença principal entre uma exceção checked e uma unchecked?

Checked obriga tratar/declarar em compilação; unchecked não.
Checked só existe em testes unitários.
Unchecked não pode ser capturada com catch.

6. Em generics, o que significa "type erasure"?

Que o tipo genérico é escolhido aleatoriamente em runtime.
Que a informação de tipo genérico existe só em compilação, não no bytecode final.
Que classes genéricas não podem ter métodos.

7. Por que um Stream só pode ser consumido (operação terminal) uma única vez?

É uma limitação de performance que será corrigida em versões futuras.
Streams representam um pipeline de execução única, não uma estrutura de dados reutilizável.
Na verdade pode ser consumido quantas vezes quiser.

8. Por que "valor++" não é seguro em múltiplas threads sem sincronização?

Porque o operador ++ não existe de fato em Java.
Porque envolve ler, somar e gravar em três passos separados, que podem intercalar entre threads.
Porque só funciona com tipos double.

9. Qual estrutura de teste representa o padrão AAA?

Assert, Assert, Assert.
Arrange, Act, Assert.
API, Application, Assertion.

10. O que o princípio de Liskov (o "L" de SOLID) afirma?

Toda classe deve implementar pelo menos uma interface.
Uma subclasse deve poder substituir sua superclasse sem quebrar o comportamento esperado.
Métodos static não podem ser sobrescritos.

11. Por que FetchType.LAZY sozinho não resolve o problema N+1?

Porque LAZY na verdade piora a performance sempre.
Porque só adia a query extra para quando o campo é acessado — ainda uma query por vez.
Porque LAZY desabilita relacionamentos completamente.

12. Um JWT decodificado revela o conteúdo do payload sem nenhuma chave secreta. Isso significa que:

JWT é assinado, não criptografado — nunca deve carregar dados sensíveis.
O JWT está corrompido e não deveria funcionar.
Isso só acontece se o servidor estiver mal configurado.

13. Qual a principal diferença entre Kafka e uma fila tradicional como RabbitMQ?

Kafka não suporta múltiplos consumidores.
Kafka retém mensagens por um período, permitindo replay; filas tradicionais removem ao confirmar.
RabbitMQ é sempre mais rápido em qualquer cenário.

14. Por que consumidores de mensageria deveriam ser idempotentes?

Porque a garantia mais comum é "at-least-once" — a mesma mensagem pode chegar mais de uma vez.
Porque idempotência é exigida por lei em sistemas de mensageria.
Porque só assim o Kafka aceita processar a mensagem.

15. Qual a diferença entre guardar um JWT em localStorage vs em um cookie httpOnly?

Cookie httpOnly é inacessível via JavaScript, reduzindo risco de roubo via XSS.
Não há diferença prática de segurança entre os dois.
localStorage é sempre mais seguro por ser mais simples.

16. Por que Testcontainers é preferível a mocks para testar um Repository JPA?

Testcontainers é mais rápido que mocks em todos os casos.
Testa contra um banco real, validando comportamento que um mock não consegue simular fielmente.
Mocks não funcionam com Spring Data JPA.

17. O que um Circuit Breaker faz quando um serviço externo falha repetidamente?

Tenta reconectar infinitamente até dar certo.
Abre o circuito e para de tentar chamar o serviço real, usando um fallback.
Reinicia a aplicação automaticamente.

18. Por que nunca usar ddl-auto=update em produção?

Porque essa opção não existe no Hibernate.
Porque o Hibernate pode alterar o schema de forma imprevisível; migrations versionadas (Flyway) são a fonte confiável.
Porque só funciona com MongoDB.

19. Por que uma imagem Docker de aplicação Java deveria usar multi-stage build?

É a única forma de o Docker funcionar com Java.
Separa o JDK/compilador (só necessário no build) do JRE enxuto necessário em runtime, reduzindo o tamanho final.
Multi-stage torna o build mais lento, mas obrigatório por segurança.

20. Por que expor uma @Entity JPA diretamente em um endpoint REST é uma má prática?

Entidades JPA não podem ser serializadas para JSON de forma alguma.
Vaza detalhes internos do banco, acopla o contrato da API ao modelo interno, e pode causar LazyInitializationException.
É proibido pelo Spring Boot em tempo de compilação.
