### 📚 Módulos Didáticos

<details>
<summary><b>1. Fundamentos & POO em Java (Capítulos 00 ao 17)</b></summary>

* **00.** Introdução, JDK, JRE, JVM & Configuração de Ambiente
* **01–04.** Classes, Objetos, Atributos, Métodos, Construtores & Encapsulamento
* **05–08.** Herança, Polimorfismo, Classes Abstratas & Interfaces
* **09–10.** Palavras-chave (`static`, `final`, `this`) & Tratamento de Exceções
* **11–15.** Collections API, Generics, Lambdas, Streams, Threads & Concorrência
* **16–17.** Princípios SOLID & Projeto Final de POO
</details>

<details>
<summary><b>2. Rumo ao Spring & Engenharia de Software (Capítulos 18 ao 28)</b></summary>

* **18–19.** Pacotes, Estrutura de Projetos, Maven & Gradle
* **20–21.** Anotações, Reflection API & Recursos do Java Moderno (Java 17/21+)
* **22–23.** Injeção de Dependência & Padrões de Projeto (Gang of Four)
* **24–27.** Persistência nativa com JDBC, Serialização JSON, APIs HTTP & Logging
* **28.** Projeto Integrador Pré-Spring
</details>

<details>
<summary><b>3. DevOps, Containers & Infraestrutura (Capítulos 29 ao 32)</b></summary>

* **29.** Fluxos de Trabalho em Git & GitHub
* **30–32.** Docker, Imagens, Dockerfile (Multi-stage Build) & Docker Compose
</details>

<details>
<summary><b>4. Bancos de Dados & Mensageria (Capítulos 33 ao 42)</b></summary>

* **33–35.** SQL Avançado, PostgreSQL na prática & Versionamento do Banco com Migrations (Flyway/Liquibase)
* **36–39.** NoSQL (MongoDB), Caching & Sessões com Redis, Estratégias de Hospedagem
* **40–42.** Arquitetura Event-Driven, Apache Kafka & Integração com Spring Kafka
</details>

<details>
<summary><b>5. Ecossistema Spring Boot & Segurança (Capítulos 43 ao 53)</b></summary>

* **43–45.** Spring Core (IoC/DI), Spring Web MVC & Spring Data JPA
* **46–50.** Resolução do Problema N+1, DTO Mapping, Bean Validation, Pagination, Swagger/OpenAPI, CORS & Rate Limiting
* **51–53.** Autenticação/Autorização (Stateful vs JWT vs OAuth2), Spring Security & HTTPS
</details>

<details>
<summary><b>6. Testes, Qualidade & Produção (Capítulos 54 ao 59)</b></summary>

* **54–55.** Testes de Integração com Testcontainers & Resiliência (Circuit Breaker / Resilience4j)
* **56–57.** Observabilidade (Spring Boot Actuator) & Gestão de Secrets em Produção
* **58–59.** CI/CD com GitHub Actions & Boas Práticas para Ambientes de Produção
</details>

<details>
<summary><b>7. Deploy, Frontend & Projeto Final (Capítulos 60 ao 67)</b></summary>

* **60–61.** Deploy em Nuvem do Backend & Frontend
* **62–64.** Integração Fullstack (Spring + React/TypeScript), Autenticação no Front & WebSockets
* **65–67.** Arquitetura e Mapa do Sistema, Projeto Integrador Final & Quiz Geral de Revisão
</details>
